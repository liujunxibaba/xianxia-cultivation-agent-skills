# 强制 Prompt 输出模板

本文件定义交给下一环节的唯一输出协议。必须按顺序填充并输出纯净 Prompt，不得改为 YAML、表格、字段摘要或其他平台模板。

## 填充规则

- 方括号内容均为待填字段，最终输出不得残留任何方括号占位符或斜杠候选项。
- 根据输入选择唯一、具体、可见、可执行的描述，不用抽象形容词代替空间和动作事实。
- 仅在有对应对象或素材时保留人物、道具和参考图行；没有人物 C 或道具 B 时删除整行。
- 未提供任何参考图时删除对应参考图行，不得虚构。未提供【位置参考图】时，将位置段首句改为“未提供【位置参考图】，以下人物位置关系依据分镜空间设计确定：”。
- 无背景人物时写“背景无其他人物”；无对白的镜头删除对白专用段落；不得自行新增对白、旁白或音乐。
- 仙侠项目中的法宝、兵器、灵兽、法阵和法术媒介可映射到道具字段，但必须使用具体名称。
- 镜头数量按叙事需要增减。每镜只设一个主导动作，并完整写出起势、过程、反馈和收势。
- 每镜开始状态必须逐项继承上一镜结束状态。任何人物位置、左右关系、朝向、视线、姿势、道具持有者/所在手/方向/状态、伤势或法术阶段的改变都必须在镜头内展示过程。
- 对白时长按自然语速校验，必须在镜头结束前说完。
- 默认声音策略为“有音效，无音乐”。只有用户明确要求音乐或旁白时才可改写相关硬锁。
- 输出时不要添加标题说明、创作思路、能力清单、自检报告、Markdown 代码围栏或“以下是提示词”等前后缀。

## 静默验收

输出前逐项检查，不向用户展示检查过程：

1. 顺序是否为参考图、位置、场景、风格、分镜、声音、动态、连续性、光线。
2. 是否存在任何未填方括号、斜杠候选项、空字段或模板说明。
3. 每镜是否包含镜头参数、开始状态、完整动作、反馈、结束状态和时长。
4. 下一镜开始状态是否与上一镜结束状态逐项一致。
5. 是否发生人物换位、跳轴、瞬移、姿势突变、道具换手或法术阶段跳变。
6. 参考图是否真实存在且用途唯一，位置参考图是否只约束空间关系。
7. 对白是否来自输入、能在镜头时长内说完且仅指定人物开口。
8. 是否默认有音效、无音乐、无旁白，且声音与动作同步。
9. 所有人物与环境受光是否来自场景中的真实光源和可见法术光源。
10. 最终文本是否可被下一环节直接投喂，无需重新整理。
