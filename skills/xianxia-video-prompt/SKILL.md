# 仙侠 AI 视频提示词

采用两层架构：先在内部生成平台无关的仙侠导演母版，再把结果填入唯一的对外交付格式。平台适配不得反向改写剧情，也不得改变交付格式的章节顺序。

每次必须完整读取 `references/universal-master.md` 和 `references/prompt-template.md`。只有用户指定平台或要求平台成品版时，再读取 `references/platform-adapters.md`。

## 可设定项

**用户提供视觉设定时以用户为准；用户未提供时根据意向自行决定以下各项**：

- **灵力色谱**
- **法宝状态**
- **角色外观**
- **环境风格**
- **禁止元素**

## 工作流

1. 检查输入（分镜/剧本/描述）、时长、画幅、资产、起始状态和段末状态；非阻塞缺项标记待定。
2. 按通用母版在内部建立连续性事实表，不向用户输出 YAML 中间稿。
3. 指定平台时建立能力探测表；未指定平台时使用平台无关措辞，不猜测专属参数。
4. 把全部事实填入 `prompt-template.md` 的固定骨架；只输出已填充的纯净 Prompt。
5. 删除不适用的可选行，禁止保留方括号占位符、斜杠候选项、解释文字或能力待确认清单。
6. 对照母版执行静默保真检查，再检查素材、轴线、状态继承、语速、时长、声音和光线。

## 仙侠生成红线

- 法术不是默认光球；优先体现职业、媒介、轨迹、材质和规则差异。
- 参考图只锁定声明的属性，不默认继承构图与动作。
- 灵力发光会成为场景光源，必须与人物受光一致。
- 禁止无剧本依据增加漂浮人物、飞剑、花瓣、仙鹤、雾气或群众。
- 提示词末尾写可见段末状态，不写"衔接下一段"等管理语。

## 强制输出协议

- 唯一交付物是 `references/prompt-template.md` 定义的纯净 Prompt；不要附加母版、分析、转换说明、参数建议或自检报告，除非用户明确要求。
- 固定章节顺序：参考图映射 → 人物位置关系 → 场景 → 整体画面风格 → 分镜 → 声音 → 动态风格 → 连续性 → 光线。
- 单镜头固定顺序：切镜方式/景别/机位/焦段/运镜 → 开始状态 → 完整动作过程 → 其他人物反馈 → 结束状态 → 时长。
- 每镜开始状态逐项继承上一镜结束状态；任何位置、姿势、视线、朝向、道具持有手或法术状态变化都必须展示变化过程。
- 有对应素材才输出参考图行；未提供位置参考图时明确说明位置关系依据分镜空间设计确定，不得虚构参考图。
- 输出前静默检查并消除所有未填占位符、候选项、人物换位、跳轴、道具换手、额外对白、旁白、音乐和虚构素材。

平台能力不足时优先拆分生成单元或压缩低收益修饰词，不得改变上述交付协议和连续性事实。
