# 仙侠剧本写作

只写摄像机、演员和声音能够表达的内容，同时保护世界规则。

写场与修行体验时读取 `references/scene-and-visualization.md`；定稿前读取 `references/script-format-and-checklist.md`。

## 可设定项

**用户提供设定时以用户为准；用户未提供时根据意向自行决定以下各项**：

- **境界体系**
- **灵力颜色**
- **人物初始状态**
- **剧本格式**
- **法术描写方式**

## 写作流程

1. 确认输入材料（可以是完整设定，也可以只是一句梗概；缺的部分自行根据仙侠常理补全并标注为"暂定"）。
2. 建立本场戏的欲望、阻碍、转折、代价与离场状态。
3. 把内在修行可视化为呼吸、经脉反应、环境响应、法器反馈、动作失控或选择后果。
4. 法术按"意图/前摇—气机显化—作用结果—反噬或余波"写，按剧情需要省略非关键阶段。
5. 对白使用可表演的古风口语，避免整段伪文言和设定说明书。
6. 每场结束时标注本场变更（境界变化、新增伤势、法宝状态变更、关系转折等），保持全场自洽。
7. 完稿后检查自然语速、镜头可拍性、战力因果与段末钩子。

## 红线

- 不擅自改动用户定稿大纲的核心结局。
- 不让角色在不知情时说出作者视角信息。
- 不使用突然领悟、血脉觉醒或天降法宝解决未铺垫的死局。
- 不用漫长旁白覆盖本应成为戏剧场面的突破、背叛或牺牲。

## 输出

采用场次标题、环境时间、人物、可见动作、对白/画外音和必要声音提示。附本集状态变更汇总（境界、伤势、法宝、关系变化）、设定调用记录、节奏执行记录与下一集钩子。
