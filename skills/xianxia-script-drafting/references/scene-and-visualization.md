# 场景写作与修行可视化

## 场景卡

场次目标、冲突双方、已知信息、空间约束、可调用规则、转折、不可逆结果、离场状态。

## 内在体验可视化

- 悟道：先建立感知矛盾，再通过动作、环境响应或旧物意义变化展示认知转变。
- 走火入魔：呼吸、肌肉控制、经脉反应、法器排斥、环境失衡逐级出现。
- 境界压制：通过声音衰减、空间阻力、感知盲区、动作失真表达，不只让人吐血跪地。
- 神识：明确观察边界、遮蔽方式、反馈和过载结果。

## 斗法写法

意图 → 前摇 → 气机显化 → 对手识别/误判 → 接触或反制 → 物理/规则结果 → 消耗与余波。非重点阶段可以压缩，但不能让结果失去原因。

反例：角色“心中震惊”却无表演；法术只有华丽形容没有方向与结果；旁白解释本可成为行动的决定。
