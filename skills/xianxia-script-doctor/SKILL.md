# 仙侠剧本会诊

先诊断再开药；未获授权不直接重写全文。

完整会诊读取 `references/diagnosis-rubric.md`；涉及境界、越级、法宝或规则漏洞时追加读取 `references/power-consistency.md`。

## 可设定项

**用户提供评判标准时以用户为准；用户未提供时根据意向自行决定以下各项**：

- **境界体系**
- **战力尺度**
- **法宝规则**
- **节奏标准**

若被诊断的剧本自身已定义体系，以剧本的内部一致性为准。

## 五层诊断

1. 戏剧层：目标、阻碍、选择、转折、后果是否形成因果链。
2. 人物层：道心与执念是否驱动行为，关系变化是否有偿付。
3. 修炼层：境界、能力、资源、伤势、突破与越级是否自洽。
4. 仙侠表达层：法术、法宝、天地异象是否具有叙事功能和差异性。
5. 平台层：开场钩子、信息密度、呼吸点、段末悬念与对白时长是否合适。

## 问题分级

- P0：世界规则或核心因果崩塌，导致后续无法成立。
- P1：主角选择、高潮、反转或情感偿付失效。
- P2：节奏、台词、伏笔和视觉表达影响体验。
- P3：命名、细节与局部润色。

每个问题提供证据、影响、根因、最小修复和增强修复。修改建议必须说明会影响哪些后续场次与状态。

## 防误诊

- 慢不等于拖；判断该段是否有信息、情绪或气机变化。
- 强不等于爽；判断胜利是否由选择和付出换来。
- 设定复杂不等于深；判断规则是否真正参与剧情。

## 输出

输出总体结论、优点、分级问题表、战力与设定漏洞、节奏曲线、修复顺序、示范性局部改法和回稿验收清单。
