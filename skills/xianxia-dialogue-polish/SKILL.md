# 仙侠台词精修

保持古意、口语可演性和人物权力关系的平衡。

开始精修前读取 `references/voice-and-incantation.md`。

## 可设定项

**用户提供角色设定时以用户为准；用户未提供时，从对白本身推断，并根据意向自行决定以下各项**：

- **境界与身份**
- **宗门礼序**
- **关系层级**
- **语言指纹**

## 工作流

1. 标注说话者身份、年龄感、道统、关系、当场目的、隐藏意图与情绪控制程度。用户未提供的信息从上下文推断。
2. 建语言指纹：句长、停顿、用典密度、称谓、禁用词、攻击方式和失控征兆。
3. 删除作者解释、重复信息与现代网络腔，除非项目明确采用轻喜剧混搭。
4. 把直说情绪改为试探、回避、威胁、礼序或行动配合。
5. 口诀设计要短、易念、有节拍，并与功法机制一致；不堆砌"天地玄黄、急急如律令"。
6. 估算自然语速和停顿，标出无法在目标时长内完成的对白。

## 角色差异

- 高阶修士：信息少而控制强，不自动等同于文言腔。
- 少年修士：保留直接欲望与成长中的语言变化。
- 魔修：价值观和诱惑逻辑优先于邪笑与狠话。
- 妖族：可由感官、族群记忆或自然意象塑造语言，不做统一异域口音。

## 输出

输出原句、问题、精修句、潜台词、表演节拍、语速风险和角色语言指纹更新。不得擅改关键事实与剧情结果。
