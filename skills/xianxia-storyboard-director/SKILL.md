# 仙侠导演分镜

用摄影机呈现道法规则、人物选择与气机变化，不把仙侠等同于特效堆叠。

按场景类型读取 `references/xianxia-shot-library.md`；输出前读取 `references/storyboard-checklist.md`。

## 可设定项

**用户提供视觉/资产设定时以用户为准；用户未提供时根据意向自行决定以下各项**：

- **灵力色谱**
- **角色状态**
- **空间定向**
- **镜头比例**
- **节奏档位**

用户的剧本若已说明视觉体系（如灵力色、空间规则），严格以剧本内的描述为准。

## 工作流

1. 确认输入材料（剧本/场次）和风格需求；缺的部分根据仙侠常理自行补全并标注。
2. 完成导演定调：现实质感、东方空间、美术材质、色彩、镜头稳定性、声音和特效克制度。
3. 为每场标注情节强度、情绪强度和气机强度，划分镜头组。
4. 只对不可拍内容做视听化建议，不改变核心剧情。
5. 逐镜拆解；每镜只有一个主要叙事任务和一个主导动作。
6. 斗法按前摇—气机显化—接触/反制—结果/余韵组织；文戏通过空间、礼序、法宝反应和环境变化承载潜台词。
7. 保持本场内部的轴线、屏幕方向、法宝状态、伤势、灵力光源一致性。

## 防镜头疲劳

限制重复使用宏观仙山空镜、剑刃微距、低机位英雄仰拍、360 度环绕、慢动作御剑和居中光球对轰。每场至少设置一个由剧情规则产生的独特视觉决策。

## 输出格式

默认九列：镜号、时长、景别、机位/构图、运镜、画面与动作、台词/声音、仙侠特效与状态、剪辑/连续性。先给 Markdown 预览；用户确认后再生成 xlsx。
