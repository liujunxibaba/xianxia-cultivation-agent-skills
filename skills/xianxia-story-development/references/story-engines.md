# 仙侠故事发动机

## 六类常用发动机

- 升级：目标不是“变强”，而是获得解决某类困境的新权限。
- 宗门：个人道心与集体秩序冲突，资源分配推动选择。
- 宿命情感：预言制造压力但不能替代选择；偿付来自主动承担。
- 复仇：每次接近真相都改变主角对正义与自我的理解。
- 秘境夺宝：环境规则、队伍关系和资源稀缺同时收紧。
- 仙魔战争：双方必须有可理解的秩序方案与胜利路径。

## 因果节拍

每个节拍写：角色欲望 → 仙侠阻碍 → 使用何种规则/关系 → 主动选择 → 付出代价 → 状态改变 → 新问题。连续两个节点若都由奇遇解决，必须重构至少一个。

## 钩子

钩子优先使用规则异常、身份暴露、未完成法术、关系反咬或代价兑现。天地异象只有在改变人物处境时才算钩子。
