# 仙侠资产数据规范

## ID 前缀

角色 `CH`、服装 `CO`、场景 `SC`、法宝 `AR`、法术 `SP`、法阵 `FM`、灵兽 `BE`、异象 `OM`、参考图 `RF`。同一实体只分配一个主 ID，形态变化使用状态字段而非创建重复实体。

## 角色卡

骨相、体态、年龄感、肤发、服装层、宗门纹样、配饰、伤痕、境界外显、四视图、表情与动作范围、Must Keep、允许变化、Avoid。

## 场景卡

尺寸、方位、出入口、地标、前中后景、光源、灵气/魔气、可破坏物、人物点位、昼夜状态。多人回切或窗内外、殿内外必须增加空间示意。

## 法宝与法术

法宝记录器形、材质、尺寸、握持、认主、能量、完整度和状态机。法术记录起源、颜色、材质、轨迹、速度、范围、命中、余波、反噬与场景受光。
