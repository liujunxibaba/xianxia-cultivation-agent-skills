# 修炼与境界设计

每个境界使用同一张表：名称、核心变化、感知范围、身体承载、规则权限、寿元、资源需求、突破条件、失败结果、外显征象、下位压制、高位限制。

## 设计原则

- 境界差至少影响信息、承载、控制或规则权限之一，不只增加破坏力。
- 突破同时改变能力、社会身份和风险。
- 越级胜利必须来自信息差、克制、地利、代价或预先布局，不能只靠意志爆发。
- 同阶也要因道统不同形成战术差异。

## 压力测试

1. 低阶主角面对高两阶敌人，有没有合理的逃生而非击杀路径？
2. 灵气断绝时，哪些职业仍可行动？
3. 连续突破是否绕过寿元、心境、资源或身体承载？
4. 最强者为何没有直接解决所有社会问题？

反例：境界只写“一阶强十倍”；临场喊一句就突破；突破后能力与行为完全不变。
